# ✨ TypeGlow

A sleek, modern, and interactive typing speed test application that helps you track and improve your typing speed (WPM) in real-time. Built with pure HTML, Vanilla JavaScript, and beautifully styled with Tailwind CSS.

---

## 🚀 Features

- ⚡ **Real-time WPM Calculation**: Accurately tracks your Words Per Minute as you type.
- ⏱️ **Active Timer**: Keeps track of how long you've been practicing.
- 🔄 **One-Click Refresh**: Quickly reload new text to practice again.
- 🎨 **Sleek UI Design**: A minimalist, dark-themed indigo aesthetic powered by Tailwind CSS that is easy on the eyes.

---

## 🛠️ Tech Stack

| Technology | Description |
|:---:|:---|
| **HTML5** | Core structure and layout elements |
| **JavaScript** | All typing logic, WPM calculation, and DOM manipulation |
| **Tailwind CSS** | Utility-first CSS framework (via CDN) for rapid and beautiful styling |

---

## 💻 Getting Started

Since TypeGlow is entirely client-side, running it locally is incredibly simple! No build steps, no servers, no fuss.

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/DishantSaini55/TypeGLow.git
```

### 2️⃣ Navigate & Open
Navigate into the directory and simply open the `index.html` file in your preferred modern web browser (Chrome, Firefox, Edge, Safari, etc.).

### 3️⃣ Start Typing!
Click on the input field and start typing the displayed text to measure your speed!
