# TypeGlow

A sleek and interactive typing speed test application built with HTML, JavaScript, and Tailwind CSS. 

## Features
- **Real-time WPM Calculation**: Accurately tracks your Words Per Minute as you type.
- **Timer**: Keeps track of how long you've been typing.
- **Refresh Capability**: Easily reload new text to practice again via the refresh button.
- **Sleek UI**: Styled using Tailwind CSS for a modern, dark-themed (indigo) aesthetic.

## Tech Stack
- **Frontend**: HTML5, JavaScript (Vanilla)
- **Styling**: Tailwind CSS (via CDN)

## How to Run
Since this is a client-side application without any build steps or server requirements, running it is incredibly simple:
1. Clone the repository or download the source code.
2. Open the `index.html` file in your preferred web browser.
3. Start typing in the input box to measure your speed!
